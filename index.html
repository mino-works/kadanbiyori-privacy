プライバシーポリシー

制定日：2026年9月30日　改訂日：2026年10月7日

mino works（以下「開発者」）は、スマートフォン用アプリ「花壇びより」（以下「本アプリ」）における利用者の情報の取り扱いについて、次のとおり定めます。

1. 開発者が集める情報

本アプリは、利用者の氏名、メールアドレス、電話番号などの個人情報を、開発者が収集することはありません。アカウント登録やログインの機能はなく、開発者のサーバーもありません。アクセス解析やクラッシュ収集のツールも組み込んでいません。

ただし、無料で提供を続けるため、本アプリには Google LLC の広告配信サービス「Google AdMob」を組み込んでいます。AdMob は「8. 広告について」に書いた情報を取得します。

2. 端末の中に保存する情報

本アプリは、遊ぶために必要な次の情報を、利用者の端末の中だけに保存します。これらの情報が、開発者や第三者に送られることはありません。

  • 庭の状態（植えた花、たね、しずく、どんぐり、飾り、レベル、庭の名前、図鑑・押し花帳の記録、冬至・お正月・春などの季節の催しの記録、おみくじの結果）
  • 「花壇みち」の進み（次に解く花壇の番号、その日に解いた数、花壇の大きさごとに解いた数、これまでで いちばん大きな花壇）と、その日に解いた花壇ならべの数（全画面の広告を出す回を決めるため）
  • 「おひさま」の記録（持っている数、その日に動画を見た日と回数、はじめのおひさまを受け取ったかどうか、使った数、雑貨店で おひさまを買った日と数、レベル20のあとに たまった ひかり）
  • 「たねころりん」を回した日と、その日に回した回数
  • もちどんの はじめての案内（ひとこと）を、どれまで表示したか（同じ案内を2回出さないため）
  • 「おすそわけ」のための記録：庭のしるし（はじめて開いたときに端末の中で作る乱数と、庭を始めた日。自分のあいことばを自分で受け取れないようにするために使います）、受け取りに使ったあいことば（新しいものから60個まで。同じあいことばで2回受け取れないようにするため）、受け取った日と回数
  • パズル（花壇ならべ・じょうろ算）の記録（日付、クリアの有無、タイム、ヒントの回数、★の数）、おまけ・ごほうびを受け取った記録、連続日数、おひるねクッション
  • 設定（効果音・BGM、お知らせのオン・オフ、大きな文字、動きを減らす など）
  • インストールした日（日ごとに開く遊びの管理のため）
  • 広告のはじまりの日、広告を表示した日時と回数、広告を見てごほうびを受け取った日（広告の回数を制限するため）、トラッキングについての説明を表示したかどうか
  • レビューのお願い（端末の OS が表示する評価の画面）を表示した日（お願いの回数を制限するため）
  • 広告を消す購入をしたかどうか
  • 保存データが壊れたときに庭を元に戻すための、1つ前の保存データ
  • iPhone のホーム画面のウィジェットに表示する、庭の絵（昼・夜・あしたの朝の3枚）と値（その日の遊びを終えた日、あした咲く花の数と色、連続日数、最後に開いた日）。本アプリを閉じたときなどに、本アプリとウィジェットだけが使える端末の中の場所（App Group）に書きます。ウィジェットは、この絵と値を表示するだけで、通信はしません。

これらの情報は、端末の OS の機能（iCloud バックアップ、Android のバックアップなど）によって、利用者自身のバックアップに含まれることがあります。バックアップの扱いは、各 OS の提供元の方針に従います。

3. 情報の削除

本アプリを端末から削除（アンインストール）すると、本アプリが端末に保存した情報（ウィジェットの絵と値を含みます）はすべて削除されます。削除した記録は元に戻せません。開発者は利用者の情報を持っていないため、開発者の側で削除する情報はありません。広告を消す購入は、再インストールのあとに、本アプリの「設定」→「購入を 復元」で戻せます。

Google が取得した広告の情報については、「8. 広告について」に書いた方法で、広告IDのリセットや、パーソナライズ広告のオフができます。

4. 写真とシェア

庭の写真、花言葉カード、パズルの結果の文は、本アプリが端末の中で作ります。「シェア」を押すと端末のシェア機能が開き、送る内容と送り先は利用者が選びます。送った後の情報の扱いは、送り先のアプリやサービスの方針に従います。本アプリが自動で送ることはありません。本アプリは、端末の写真やカメラ、連絡先、位置情報（GPS）にはアクセスしません。

花言葉カードには、「おすそわけ」のあいことば（10文字の英数字）が入ることがあります。あいことばに入っているのは、花の種類、カードを作った日、庭のしるしから作った短い印だけで、氏名や端末の識別子は入っていません。あいことばの入ったカードをシェアするときの文には、あいことばと庭の名前（名前をつけていない場合は「わたしの庭」）が入ります。あいことばは、利用者が自分でシェアしたり、人に伝えたりするだけです。受け取る側が入れたあいことばも、端末の中だけで確かめます。おすそわけのために、本アプリが情報を外部に送ることはありません。

5. お知らせ（通知）

本アプリは、庭に変化がある日（花が咲いた朝など）に、毎朝8時ごろのお知らせを、端末の中だけで予約して表示します（ローカル通知）。通知のために情報を外部に送ることはありません。お知らせを宣伝や広告には使いません。お知らせを受け取るかどうかは、はじめて芽が出たときに選べ、本アプリの「設定」または端末の設定でいつでも変えられます。

6. 子どもの利用

本アプリは、大人の方に向けて作っており、13歳未満の子どもを対象にしていません。広告は、どなたが見ても問題のない内容（一般向け：G 相当）に限って表示します。

7. 第三者への提供

開発者は、利用者の個人情報を第三者に提供しません。ただし、「8. 広告について」「11. 外部送信について」に書いたとおり、広告のために、利用者の端末から Google に情報が送られます。

8. 広告について

本アプリは、広告の表示に Google AdMob を使います。広告は次の場面だけに表示します。パズル（花壇ならべ・じょうろ算）を遊んでいる間と、本アプリを開いた直後には表示しません。画面の下に出るバナー広告はありません。

  • 利用者が自分で選んだとき：おひさま、しずく、ふしぎな種、どんぐり2倍、おひるねクッションを受け取るために「広告を見て もらう」を選んだ場合（動画など）。見なくても、本アプリはすべて遊べます（株は日付が変わると育ち、おひさまも遊ぶ中で手に入ります）。トラッキングを許可したかどうかで、受け取れるものは変わりません。
  • 全画面の広告：花壇ならべ（「きょうの花壇」と「花壇みち」）を、その日に3つ解くごとに1回。解いた花壇の花が咲きそろったあと、ごほうびのカードの前に表示します（そのときは盤面の下に「広告の あと ごほうび」と出ます）。じょうろ算とお手本の花壇は数えません。

「広告のはじまりの日」は、広告を始めたバージョン以降の本アプリをはじめて開いた日です（それより前から遊んでいる方は更新して開いた日、新しく始めた方は庭を始めた日）。自分で選んで見る広告は、この日から選べます。全画面の広告は、この日は9つ目の花壇のあとから、翌日からは3つ目の花壇のあとから表示します。本アプリを開いた直後、ごほうびのカードの上、レビューのお願いを出すとき、前の全画面の広告から3分たっていないときは、全画面の広告を表示しません。

AdMob は、広告の配信、効果の測定、不正の防止のため、次の情報を取得することがあります。

  • 広告ID（iPhone の IDFA、Android の広告ID）、アプリごとの識別子（iPhone の IDFV、Android の App Set ID など）
  • IPアドレス（おおよその地域の推定に使われることがあります）
  • 広告の表示やタップ、動画の視聴などの操作の情報
  • 端末の種類、OS のバージョンなどの技術的な情報、アプリや広告の動作に関する診断情報（起動時間、クラッシュなど）

パーソナライズ広告について

  • iPhone では、本アプリをはじめて起動したとき、本アプリの説明（「広告について」）を表示したあとで、端末の「トラッキングの許可」の確認を出します。利用者が「許可」した場合に限り、IDFA を使った広告の最適化（パーソナライズ広告）を行います。許可しなくても、本アプリはすべて同じように使えます。許可は、端末の「設定」→「プライバシーとセキュリティ」→「トラッキング」からいつでも変えられます。
  • Android では、端末の「設定」→「プライバシー」→「広告」（機種により「Google」→「広告」）から、広告IDの削除やリセットができます。
  • 欧州経済領域（EEA）、英国、スイスの利用者には、Google の同意管理の仕組みで、情報の利用について同意をうかがいます。本アプリの「設定」→「プライバシー設定（広告）」から、いつでも選択を変えられます（同意が必要な地域でだけ表示されます）。
  • 広告を消す購入をした場合、本アプリは広告の仕組みを起動せず、広告のための情報も送りません。トラッキングの許可の確認も出しません。

不適切な広告の報告

不適切な広告や、年齢に合わない広告を見かけたときは、広告の［i］や［×］から Google に報告できます。「12. お問い合わせ」の連絡先から、開発者にもお知らせください。

Google による情報の扱いは、次をご覧ください。

  • Google のプライバシーポリシー：https://policies.google.com/privacy
  • Google のパートナーのサイトやアプリからの情報の利用：https://policies.google.com/technologies/partner-sites
  • 広告の設定（パーソナライズ広告のオフ）：https://myadcenter.google.com/

9. アプリ内課金について

本アプリでは、広告を消すオプション（買い切り）を販売します。購入すると、全画面の広告が出なくなり、しずくなどのごほうびも広告なしで受け取れます。購入しなくても、すべての機能は無料で使えます。

購入の手続きと支払いは、Apple（App Store）または Google（Google Play）が行います。開発者が、クレジットカードの番号などの支払いの情報を受け取ることはありません。購入の状態は各ストアの仕組みで確かめ、その結果を端末の中だけに記録します（開発者のサーバーには送りません）。

10. このポリシーの変更

開発者は、必要に応じてこのポリシーを変更します。情報の扱いが変わる場合は、アプリの更新の前に、このページで変更の内容と改訂日をお知らせします。

  • 2026年10月7日：「おひさまのかけら」の呼び名を「おひさま」に変え、雑貨店で おひさまを買えるようにし、「たねころりん」を1日に何回でも回せるようにし、はじめての案内を加え、はじめた日の全画面の広告を9つ目の花壇のあとからにしたため、2・8・11 を改訂しました。
  • 2026年10月5日：「おすそわけ」（あいことば）、ホーム画面のウィジェット、「たねころりん」、春の催し、「おひさまのかけら」を加え、「花壇みち」を続けて遊べるようにし、全画面の広告を表示する場面と回数を変えたため、2・3・4・8・11 を改訂しました。
  • 2026年10月3日：広告（Google AdMob）とアプリ内課金（広告を消す買い切り）を始めるため、1・2・3・5・6・7・8・9・11 を改訂しました。

11. 外部送信について

本アプリは、次のとおり、利用者の端末から外部に情報を送信します（利用者に関する情報の外部送信の公表）。

送信先送信される情報目的
Google LLC（Google AdMob、同意管理の仕組みを含む）広告ID・アプリごとの識別子、IPアドレス、端末と OS の情報、広告の表示・操作の情報、診断情報、同意の選択広告の配信、広告の効果の測定、不正な利用の防止、同意の管理
Apple Inc.（App Store）／Google LLC（Google Play）購入と購入の復元の手続きに必要な情報（各ストアの仕組みで送られます）アプリ内課金の処理

広告を消す購入をした場合、Google AdMob への送信は行いません。

「おすそわけ」のあいことばの確認、ホーム画面のウィジェット、「たねころりん」、「花壇みち」、「おひさま」（雑貨店で買う分を含みます）、もちどんの はじめての案内は、すべて端末の中だけで動き、外部への送信はありません。

本アプリの「設定」からこのページやサポートのページを開くと、端末のブラウザ（Safari など）が、ページを置いている GitHub Pages（GitHub, Inc.）に接続します。この接続での情報の扱いは、ブラウザと GitHub の方針に従います。
