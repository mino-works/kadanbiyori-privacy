プライバシーポリシー

制定日：2026年9月30日

かんたんに言うと：

  • 氏名やメールアドレスなどの個人情報を、開発者が集めることはありません。アカウント登録もありません。
  • 庭や遊んだ記録は、あなたの端末の中だけに保存します。
  • 本アプリから外部に情報を送ることはありません。
  • 現在、広告は表示していません。アプリ内課金もありません。

KOHEI MINOSHIMA（以下「開発者」）は、スマートフォン用アプリ「花壇びより」（以下「本アプリ」）における利用者の情報の取り扱いについて、次のとおり定めます。

1. 開発者が集める情報

本アプリは、利用者の氏名、メールアドレス、電話番号などの個人情報を、開発者が収集することはありません。アカウント登録やログインの機能はなく、開発者のサーバーもありません。アクセス解析やクラッシュ収集のツールも組み込んでいません。

2. 端末の中に保存する情報

本アプリは、遊ぶために必要な次の情報を、利用者の端末の中だけに保存します。これらの情報が、開発者や第三者に送られることはありません。

  • 庭の状態（植えた花、たね、しずく、どんぐり、飾り、レベル、庭の名前、図鑑・押し花帳の記録）
  • パズル（花壇ならべ・じょうろ算）の記録（日付、クリアの有無、タイム、ヒントの回数、★の数）、おまけ・ごほうびを受け取った記録、連続日数、おひるねクッション
  • 設定（効果音・BGM、お知らせのオン・オフ、大きな文字、動きを減らす など）
  • インストールした日（日ごとに開く遊びの管理のため）
  • 保存データが壊れたときに庭を元に戻すための、1つ前の保存データ

これらの情報は、端末の OS の機能（iCloud バックアップ、Android のバックアップなど）によって、利用者自身のバックアップに含まれることがあります。バックアップの扱いは、各 OS の提供元の方針に従います。

3. 情報の削除

本アプリを端末から削除（アンインストール）すると、本アプリが端末に保存した情報はすべて削除されます。削除した記録は元に戻せません。開発者は利用者の情報を持っていないため、開発者の側で削除する情報はありません。

4. 写真とシェア

庭の写真、花言葉カード、パズルの結果の文は、本アプリが端末の中で作ります。「シェア」を押すと端末のシェア機能が開き、送る内容と送り先は利用者が選びます。送った後の情報の扱いは、送り先のアプリやサービスの方針に従います。本アプリが自動で送ることはありません。本アプリは、端末の写真やカメラ、連絡先、位置情報（GPS）にはアクセスしません。

5. お知らせ（通知）

本アプリは、庭に変化がある日（花が咲いた朝など）に、毎朝8時ごろのお知らせを、端末の中だけで予約して表示します（ローカル通知）。通知のために情報を外部に送ることはありません。お知らせを受け取るかどうかは、はじめて芽が出たときに選べ、本アプリの「せってい」または端末の設定でいつでも変えられます。

6. 子どもの利用

本アプリは、大人の方に向けて作っており、13歳未満の子どもを対象にしていません。本アプリは、子どもを含むどなたの情報も収集しません。

7. 第三者への提供

開発者は、利用者の個人情報を第三者に提供しません。本アプリが、利用者の情報を第三者に送ることもありません（「11. 外部送信について」）。

8. 広告について

本アプリは、現在、広告を表示していません。広告の配信サービスも組み込んでいません。

将来、広告を導入する場合は、その前に本ページを更新し、広告のために取得・送信される情報、送信先、利用者が選べることをお知らせします。

9. アプリ内課金について

本アプリには、現在、アプリ内課金はありません。すべての機能を無料で使えます。

将来、アプリ内課金を導入する場合は、その前に本ページを更新し、情報の扱いをお知らせします。

10. このポリシーの変更

開発者は、必要に応じてこのポリシーを変更します。情報の扱いが変わる場合は、アプリの更新の前に、このページで変更の内容と改訂日をお知らせします。

11. 外部送信について

本アプリは、現在、利用者の端末から外部に情報を送信していません（利用者に関する情報の外部送信はありません）。

本アプリの「せってい」からこのページやサポートのページを開くと、端末のブラウザ（Safari など）が、ページを置いている GitHub Pages（GitHub, Inc.）に接続します。この接続での情報の扱いは、ブラウザと GitHub の方針に従います。

将来、外部への送信を始める場合は、その前に本ページで、送信先・送信される情報・目的をお知らせします。
